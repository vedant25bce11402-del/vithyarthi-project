# vithyarthi-project
Number Guessing Game
A simple interactive Python game where the player tries to guess a secret number randomly chosen within a given range. The game offers clear feedback for each guess and limits the number of attempts, making it both a fun and accessible introduction to basic Python programming concepts like loops, conditionals, input validation, and error handling.

Features
User-friendly prompts and instructions.
Secret number is randomly generated within a configurable range.
Guessing feedback ("Too low" / "Too high") after each attempt.
Limited number of attempts (adjustable for difficulty).
Robust input validation (handles non-numeric and out-of-bounds input).
Congratulations message if guessed correctly, or reveals the secret number if attempts run out.

How to Play
Run the script in your Python environment.
Follow the prompts to guess the secret number.
Enter whole numbers only; invalid or out-of-range input will not count against your attempt limit.
Win by guessing the number within the allowed attempts, or lose and see the correct answer.
